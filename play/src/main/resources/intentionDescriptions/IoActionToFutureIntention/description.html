Turns a Play action whose body produces an IO[Result] (or F[Result] with a Dispatcher[F] in scope) into the Play 3 bridge Action.async { io.unsafeToFuture() }. It uses the runtime the class already has: an implicit IORuntime, an injected runtime: IORuntime (passed explicitly) or a Dispatcher; otherwise it adds import cats.effect.unsafe.implicits.global.
