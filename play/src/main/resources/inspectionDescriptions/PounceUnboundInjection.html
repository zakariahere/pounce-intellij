Reports an @Inject() constructor parameter whose type Guice cannot provide, which fails at application start with a ConfigurationException:
  • a trait / abstract class with no bind(classOf[A]).to(...), bind[A].to[B], @Provides method, @ImplementedBy or @ProvidedBy;
  • a project class without an @Inject or no-argument constructor and no binding.

Conservative: types bound by Play, Pekko and Guice themselves (play.*, org.apache.pekko.*, com.google.inject.*, javax/jakarta.inject.*, com.typesafe.config.*, ExecutionContext, ...) are never reported, nor are library types from jars that ship a Guice/Play module, types mentioned anywhere inside a Guice/Play module, and projects using compile-time DI (BuiltInComponentsFromContext).
