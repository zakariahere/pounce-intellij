Reports a config path read from Scala code that is not defined in the project's application.conf (including included files and application.<env>.conf variants) nor in any library reference.conf — a ConfigException.Missing at runtime.

Recognised reads: Configuration.get[T]("…"), getMillis, getNanos, underlying.getString("…") and every com.typesafe.config.Config.getX, ConfigFactory.load().getX("…"), pureconfig ConfigSource.default.at("…").

Not reported: optional reads (getOptional, has, hasPath, get[Option[T]]), paths below a ${?ENV} substitution, relative configs whose prefix is not visible, reads guarded by has/hasPath or wrapped in Try, and projects whose conf files have unresolvable includes or do not parse.

The quick fix appends the key with a placeholder value of the read type to application.conf.
