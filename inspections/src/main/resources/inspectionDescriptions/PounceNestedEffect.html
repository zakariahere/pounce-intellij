Reports map whose function returns an effect, giving a nested effect such as IO[IO[A]] or List[IO[A]]. The inner effect is a value that nobody runs.

Before:

def save(u: User): IO[Unit] = ...

val done: IO[Unit] = findUser(1).map(save).void   // save never runs

After (quick fix Replace map with flatMap):

val done: IO[Unit] = findUser(1).flatMap(save).void

For collections and Option the fix is Replace map with traverse (ids.map(save) → ids.traverse(save)), and foreach returning an effect becomes traverse_. Not reported when the nested type is what the code expects (an explicit IO[IO[A]]) or when .flatten follows.
