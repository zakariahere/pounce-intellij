Reports a for-comprehension generator whose effect differs from the comprehension's (an Option or Either step in an IO for-comprehension). Scala reports a confusing type mismatch on the desugared flatMap; this explains it and lifts the step.

Before:

for {
  user <- findUser(id)          // IO[User]
  addr <- user.address          // Option[Address]
} yield addr

After (quick fix Lift with IO.fromOption):

for {
  user <- findUser(id)
  addr <- IO.fromOption(user.address)(new NoSuchElementException("user.address is empty"))
} yield addr

Other lifts: IO.fromEither, IO.fromFuture(IO(...)), .liftTo[F] for tagless code, EitherT.right, OptionT.liftF and Stream.eval. For a sequence of optional steps, consider OptionT / EitherT.
