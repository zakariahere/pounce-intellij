Reports hand-written error-handling combinators: attempt.map(_.toOption) → option, handleErrorWith(e => F.pure(x)) → handleError, attempt.map(_.fold(g, f)) and map(f).handleError(g) → redeem, attempt.flatMap(...) → redeemWith.

Before:

fa.attempt.flatMap {
  case Left(e)  => recover(e)
  case Right(a) => use(a)
}

After (quick fix Replace with .redeemWith):

fa.redeemWith(e => recover(e), a => use(a))

Every rewrite is checked before it is offered: the replacement must resolve, have its implicits, and keep a compatible type. The quick fix adds the cats syntax import if needed.
