Reports verbose EitherT construction. EitherT.right[E] is used instead of EitherT.liftF because liftF infers E = Nothing without an expected type.

Before:

EitherT(IO.pure(Right(1)))   // EitherT[IO, String, Int]
EitherT(io.map(Right(_)))

After (quick fix Replace with EitherT.rightT):

EitherT.rightT[IO, String](1)
EitherT.right[String](io)

Every rewrite is checked before it is offered: the replacement must resolve, have its implicits, and keep a compatible type. The quick fix adds the cats syntax import if needed.
