Reports unsafeRunSync, unsafeToFuture, unsafeRunAndForget and the other unsafe* methods used in ordinary code. Effects should be run once, at the edge of the world.

Before:

def total: Int = repo.count.unsafeRunSync()

After:

def total: IO[Int] = repo.count   // run it from IOApp / the caller

Not reported (allowed edges): test sources, a main method, the arguments of Play's Action.async (so Action.async(io.unsafeToFuture()) in a controller is fine), ApplicationLifecycle.addStopHook, Play filters / action builders / error handlers, Guice and Play DI modules (they run once at startup), and the classes and packages listed in Settings | Pounce | unsafeRun allow-list.
