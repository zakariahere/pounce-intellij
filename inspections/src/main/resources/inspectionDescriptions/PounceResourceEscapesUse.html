Reports a Resource whose acquired value is returned from use (res.use(IO.pure), res.use(x => IO.pure(x))): by the time the caller gets it, the resource has been released. Also reports res.allocated.map(_._1), which drops the release action.

Before:

val conn: IO[Connection] = pool.use(IO.pure)   // already closed

After:

pool.use(conn => runQueries(conn))

Plain data values (numbers, strings, Unit) are not reported: returning them from use is harmless.
