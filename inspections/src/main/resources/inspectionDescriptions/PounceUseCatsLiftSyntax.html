Opt-in style (INFORMATION level, no highlighting): cats lift syntax instead of constructors, which types the value as Either / Option instead of Right / Some. Offered only where the expected type is Either / Option.

Before:

val r: Either[String, Int] = Right(1)
val o: Option[Int] = Some(1)

After (quick fix Replace with .asRight):

val r: Either[String, Int] = 1.asRight[String]
val o: Option[Int] = 1.some

Every rewrite is checked before it is offered: the replacement must resolve, have its implicits, and keep a compatible type. The quick fix adds the cats syntax import if needed.
