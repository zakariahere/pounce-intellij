Reports map to a constant. Only offered when the constant is a stable value (literal, val, object, constructor of stable values), because as evaluates it eagerly.

Before:

fa.map(_ => 42)
fa.void.as(42)
fa *> IO.pure(42)

After (quick fix Replace with .as):

fa.as(42)

Every rewrite is checked before it is offered: the replacement must resolve, have its implicits, and keep a compatible type. The quick fix adds the cats syntax import if needed.
