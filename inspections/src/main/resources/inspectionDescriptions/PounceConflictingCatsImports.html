Reports cats imports that bring the same implicits into scope: cats.implicits._ with cats.syntax.all._, a granular cats.syntax.functor._ next to cats.syntax.all._, cats.instances.list._ next to cats.implicits._, and the cats-effect equivalents. In Scala 2 the duplicated implicits are ambiguous, so syntax and instances stop resolving.

Before:

import cats.implicits._
import cats.syntax.all._

After (quick fix Remove import cats.implicits._):

import cats.syntax.all._

Which import is kept follows Settings | Pounce | import style (or the style detected in the project).
