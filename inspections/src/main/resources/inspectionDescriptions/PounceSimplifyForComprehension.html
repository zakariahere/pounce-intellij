Reports for-comprehensions that do less than they look: a single generator (fa / fa.map), a later x <- F.pure(v) (a plain x = v) and a later _ <- F.unit (does nothing).

Before:

for {
  u <- findUser(1)
  n <- IO.pure(u.name)
  _ <- IO.unit
} yield n

After (quick fix Replace with a value definition):

for {
  u <- findUser(1)
  n = u.name
} yield n

Every rewrite is checked before it is offered: the replacement must resolve, have its implicits, and keep a compatible type. The quick fix adds the cats syntax import if needed.
