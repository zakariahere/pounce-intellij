Reports tuple-building by hand: mapN((a, b) => (a, b)) is tupled; product(...).map { case (a, b) => ... } is mapN.

Before:

fa.product(fb).map { case (a, b) => a + b }

After (quick fix Replace with .mapN):

(fa, fb).mapN((a, b) => a + b)

Every rewrite is checked before it is offered: the replacement must resolve, have its implicits, and keep a compatible type. The quick fix adds the cats syntax import if needed.
