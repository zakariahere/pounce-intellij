Explains a missing typeclass instance. For a tagless-final type parameter it says which bounds F has and offers to add or strengthen the bound on the declaring method or class.

Before:

def load[F[_]: Functor](id: Int): F[User] =
  Monad[F].pure(User(id))      // No Monad[F] instance

After (quick fix Strengthen bound to Monad):

def load[F[_]: Monad](id: Int): F[User] =
  Monad[F].pure(User(id))

A missing IORuntime gets a hint and Import cats.effect.unsafe.implicits.global; a missing ExecutionContext gets a hint. The related Strengthen bound to Monad fix also appears on the Scala plugin's own Cannot resolve symbol flatMap error when the bound is too weak for a cats method.
