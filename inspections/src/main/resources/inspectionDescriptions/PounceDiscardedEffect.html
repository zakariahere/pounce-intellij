Reports an effect value (IO, Resource, EitherT, fs2.Stream, or a tagless-final F[A]) that is computed and then thrown away. Effects are descriptions: one that is not sequenced into the result never runs. This is the most common cats-effect bug.

Before:

def greet: IO[Unit] = {
  IO.println("Hello")   // never printed
  IO.println("World")
}

After (quick fix Chain with the next statement using >>):

def greet: IO[Unit] = {
  IO.println("Hello") >> IO.println("World")
}

An if without else also discards its effect; the quick fix rewrites it to fa.whenA(condition). So does value discarding: def log(): Unit = IO.println("a") builds the IO and throws it away.

Not reported: Unit-returning side effects, Future (eager, it runs anyway), the result expression of a block, and expressions whose type isn't a known effect.
