Reports a typeclass bound implied by another bound of the same type parameter (F[_]: Monad: Sync: Sync is a Monad). Two evidences for Monad[F] make implicit resolution ambiguous in Scala 2, which breaks syntax like .flatMap.

Before:

def save[F[_]: Monad: Sync](u: User): F[Unit]

After (quick fix Remove redundant Monad):

def save[F[_]: Sync](u: User): F[Unit]

Works for context bounds and implicit parameters ((implicit M: Monad[F], S: Sync[F])); an implicit parameter is only removed by the fix when it is unused.
