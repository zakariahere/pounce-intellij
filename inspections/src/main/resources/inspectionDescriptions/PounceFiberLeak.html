Reports .start whose fiber is thrown away (fa.start >> fb, fa.start.void, _ <- fa.start). Nobody joins or cancels the fiber, so it keeps running (or leaks) when the rest fails or is cancelled.

Before:

worker.start >> server.serve

After (quick fix Use .background (cancel the fiber when the rest completes)):

worker.background.surround(server.serve)

A bare fa.start statement is left to the discarded-effect inspection. Generators that bind the fiber and use it (fib <- fa.start; ...; fib.join) are not reported.
